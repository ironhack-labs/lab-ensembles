# Lab | Ensembles


## Introduction

A single decision tree is easy to train and to explain, but its results change a lot with the data it sees. In this lab you predict heart disease from 13 health measurements and see how ensembles of trees deal with that: bagging and random forests to reduce variance, AdaBoost and gradient boosting to reduce bias. You will also read a random forest's feature importances, and finish by comparing every model fairly with cross-validation.

The lab follows the **Ensemble Methods** lesson step by step.


## Getting Started

Open the `main.ipynb` file in the `your-code` directory. Follow the instructions, add your code, and answer the questions in the markdown cells. The data is in `data/heart.csv`.
